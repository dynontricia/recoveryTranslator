Recovery Translator provides real-time spoken language interpretation for recovery meetings, area committees, and service assemblies — making meetings accessible to everyone regardless of the language they speak.

How It Works
The session leader opens a session from their device and shares a QR code with attendees. As the leader speaks, their words are transcribed and translated in real time. Attendees read captions on their phones in their preferred language. No special equipment is needed — just a phone and a browser.

Listeners who speak a different language can also request to speak. The session leader approves the request, and the system automatically translates their words back to the room's primary language.

Getting Access
Session leaders need an access code and an OpenAI API key to start a session. Listeners only need the session code provided by the leader — no account or API key required.

To request an access code, contact us at dynontricia@gmail.com.

Estimated Cost
Recovery Translator uses OpenAI's real-time translation API, billed directly to the session leader's OpenAI account. The estimated cost is about $0.05 per minute of active session time — typically under $5 for a two-hour meeting.

Built for Recovery
This tool was built by and for the recovery community, with anonymity and accessibility in mind. It is free to use (other than the OpenAI cost that passes directly to you) and open source.

Step-by-Step Instructions

Session Leaders
Open https://recoverytranslator-production.up.railway.app/ and tap I am a session leader.
Enter your access code, your OpenAI API key, and select the primary spoken language. Tap Start session.
Share the QR code or session code with your attendees.
Speak normally — captions and translation are live.
When a listener requests to speak, tap Approve or Deny on your screen.
When the approved speaker is finished, tap Resume main session.
When the meeting ends, tap End session.

Listeners — Primary Language
Scan the QR code or go to https://recoverytranslator-production.up.railway.app/ and tap I am a listener.
Enter the session code, select your language, and tap Join.
Captions will appear automatically as people speak.
To address the group, tap Request to speak and wait for approval.
When approved, speak clearly. Tap Done speaking when finished.

Listeners — Second Language
Scan the QR code or go to https://recoverytranslator-production.up.railway.app/ and tap I am a listener.
Enter the session code, select Español, and tap Join.
Translated captions will appear automatically as people speak.
To address the group, tap Request to speak and wait for approval.
When approved, speak clearly into your phone's microphone. Tap Done speaking when finished.
