Support

Help with Recovery Translator, on the website or in Zoom.

Contact

Email dynontricia@gmail.com. Include your session code if you have one, and what you saw. We usually reply within 2 business days.

For access codes, deleting your group's saved settings, questions about privacy, or reporting a security concern, use the same address.

Troubleshooting

The Zoom panel says no session is running

Start one in the panel. If you started it on the website, enter the Zoom link code from the leader screen under Started a session in the browser? A session only shows in the meeting it belongs to.

"No session is waiting for that link code"

Each link code works once, and only while its session is running. Check the code on the leader screen, or start the session from the Zoom panel instead.

Google rejected my Gemini key

  • Copy the whole key again from Google AI Studio, with no spaces.
  • Make sure the key's project hasn't been deleted and the Gemini API is allowed for it.

"Your saved key could not be read"

Open Settings and save your key again. Nothing else is needed.

Captions never start in Zoom

  • Make sure you allowed Zoom to share meeting audio with the app when prompted.
  • Your Zoom account admin may need to enable Realtime Media Streams for the account.
  • If you use your own key, check in Google AI Studio that billing is on and the key works.
  • Tap Pause, then Start captions again.

Captions stopped partway through

Check your internet connection. Captions reconnect on their own after a short drop. If they don't come back within a minute, tap Start captions again.

My language isn't in the list

Listeners can only pick the languages the leader chose when starting the session. Ask the leader to include it next time.

I can't hear the spoken translation

  • Tap No sound? Play a test sound on the listener screen. If you don't hear the beep, check your device's volume, silent switch, and Bluetooth.
  • Spoken translation is only offered in the languages marked 🔊, which the leader chose.
  • On a phone, keep the page open; some phones stop audio when the screen locks.

Translations are inaccurate

Translation is automatic and works best with one person speaking at a time, close to the microphone. Background noise and crosstalk lower accuracy.
